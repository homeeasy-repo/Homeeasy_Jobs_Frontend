# 02 - Assessment Path

The hiring path is staged. Candidates earn the next packet by doing the current one well.

## 1. Packet I - Business Read

Public packet. Candidate studies Blue Lake/HomeEasy and submits:

- technical evidence,
- business summary,
- revenue thesis,
- first fix,
- system sketch,
- Central Time overlap,
- compensation bid.

## 2. Packet II - Technical Build Screen

Released by email to selected candidates.

Candidate builds a small Revenue Captain service from messy records. It must include:

- durable state model,
- ranked next-action queue,
- reason codes,
- idempotent worker,
- edge-case tests,
- README and walkthrough.

## 3. Live No-AI Technical Fundamentals

Live screen without AI assistance:

- data structures,
- databases,
- concurrency,
- debugging,
- system design,
- complexity and tradeoffs.

## 4. Commercial Simulation

Candidate triages a messy operating situation and decides:

- what is known,
- what is missing,
- what action moves revenue,
- what should be automated,
- what requires a human.

## 5. Paid Sandbox Trial

Finalists complete a small audited work product against sanitized operating data. No candidate touches real production workflows without the right agreement, access control, and supervision.

## 6. Offer, Park, Or Recycle

Candidates may be:

- moved to offer discussion,
- parked for a future cohort,
- recycled when their skills improve,
- rejected with a reason code.
